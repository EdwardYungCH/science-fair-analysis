# 香港創科展：初高中歷年入圍作品分析

整理首五屆香港創科展（2022—2026年，即2021-2022至2025-2026學年）初中組及高中組共397項入圍作品，包括作品名、學校、簡介、主要功能、技術路線及競逐獎項。

## 檔案

| 檔案 | 內容 |
| --- | --- |
| `index.html` | 互動網頁（單一檔案，離線可用）：五屆比較及逐年入圍／獲獎趨勢、功能分類、各年度功能熱圖、可篩選及匯出 CSV 的完整名錄 |
| `analysis.md` | 同一份資料的文字版：統計表、趨勢分析、各屆獲獎名單及完整作品名錄 |

## 使用方法

直接用瀏覽器開啟 `index.html` 即可，毋須安裝或連線。

## 資料說明

- 作品名、學校及入圍身分依官方歷屆名單核對；簡介綜合官方 Facebook 作品介紹，以中文重新摘要；獎項依官方歷屆得獎名單核對。資料核對截至2026年10月23日。
- 功能分類及技術路線屬本整理按簡介判斷，並非主辦方分類。「提及AI」只按簡介明確寫出的字眼判斷。
- 統計只描述入圍及獲獎名單的組成，不代表評審準則或題目勝算。
